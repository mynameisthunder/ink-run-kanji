# Ink Run PDF font

`InkRunJapanese.ttf` is a glyph-subsetted, weight-500 build of Noto Sans JP. It contains the Japanese and Latin characters currently used by Ink Run's study-guide exports. Its browser-ready base64 build is `vendor/ink-run-japanese-font.js`; keeping it preloaded allows PDF downloads to work when Ink Run is opened directly from disk.
